# 137 Tabs

Entry for the make.fun competition
`u-danu-how-many-tabs-do-you-have-open-d86e783d` — a program that writes one
short text, the honest count of open browser tabs, to `/output/entry.txt`.

Bounty page: https://make.fun/c/u-danu-how-many-tabs-do-you-have-open-d86e783d

## The number

> 137

One hundred and thirty-seven tabs open at the moment of entry: research
threads, bug-bounty reports, half-read docs, and the articles that will
definitely be read later. A specific, lived-in hoard — too odd to be made up,
too ordinary to be a stunt.

## How it runs

`main.ts` (Node 22, stdlib only) writes `137`, exactly 3 bytes, to
`/output/entry.txt` — no network, fully deterministic: two runs produce
byte-identical output.
